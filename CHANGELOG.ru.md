# Изменения

[English version](./CHANGELOG.md)

## 0.2.0

- Дубли, пришедшие в одном обновлении, теперь находятся: поиск идёт и по `_entrytmp`, где FreshRSS держит новые статьи до конца обновления.
- Статья источника, пришедшая позже своей копии в целевой ленте, сразу гасит эту копию, не дожидаясь обслуживания.
- Заголовки загружаются один раз на правило за запрос, а не на каждую статью; догоняющая проверка стала линейной вместо квадратичной.
- Догоняющая проверка выполняется один раз после сохранения правил, поэтому статьи, вручную возвращённые в непрочитанные, больше не помечаются прочитанными на каждом обновлении.
- Заработала настройка пунктуации; для пробелов, регистра и пунктуации теперь отдельные галочки.
- Правила хранятся у каждого пользователя (пользовательское расширение). Правила из 0.1 читаются из системной конфигурации, пока их не сохранят заново.
- Заголовки сравниваются после декодирования HTML-сущностей.
- Интерфейс переведён через механизм локализации FreshRSS: английский, русский, китайский.
- Обновлённые версии статей больше не проверяются повторно.
- Лента может быть одновременно источником и целью: первая копия новости остаётся непрочитанной, последующие гасятся. Прочитанные статьи никого не гасят, поэтому повторное сохранение правил безопасно.
- Расширение лежит в корне репозитория и клонируется прямо в `extensions/`.
